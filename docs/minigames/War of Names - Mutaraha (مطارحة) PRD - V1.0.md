# 1. لماذا "مطارحة"؟ — اسم المنتج وهويته

## 1.1 قصة الاسم

**المطارحة** (مُطارَحة) — كلمة عربية أصيلة تعني المبارزة الفكرية. في الثقافة النجدية، المطارحة الشعرية هي تقليد عريق: شاعران يتبادلان الأبيات، كل واحد يرمي بيتاً والآخر يرد بأقوى منه. ليست معركة عضلات — هي معركة عقول.

هذا بالضبط ما تفعله اللعبة: لاعبان يتبادلان الاستنتاجات والتخمينات. كل واحد يحاول يكشف كلمات الثاني قبل ما الثاني يكشف كلماته. **مبارزة ذكاء، لا مبارزة حظ.**

## 1.2 لماذا "مطارحة" وليس اسم ثاني؟

| الاسم المقترح | ليش ما اخترناه | ليش مطارحة أفضل |
|--------------|----------------|-----------------|
| كشف المستور | وصفي — يشرح اللعبة بدل ما يكون اسم | مطارحة اسم، لا وصف |
| فراسة | حلو لكن يوحي بقراءة الناس، مو مبارزة | مطارحة فيها تحدي وجهاً لوجه |
| سبر | غامض — المستخدم ما يفهمه من أول مرة | مطارحة مفهومة ولها ثقل ثقافي |
| صيد الألقاب | طويل + يتداخل مع محرك الهجمات الأساسي | مطارحة كلمة واحدة، مستقلة |
| كمين | عدواني — يوحي بالغدر مو بالذكاء | مطارحة فيها احترام + تحدي |

## 1.3 الشعار والهوية البصرية

- **اسم العرض:** مطارحة
- **الوصف القصير:** مبارزة كلمات 1v1
- **الوصف الطويل:** خمّن كلمات خصمك قبل ما يخمّن كلماتك — مبارزة ذكاء وفراسة مستوحاة من المطارحة الشعرية النجدية
- **الأيقونة المقترحة:** سيفان متقاطعان مع حرف عربي في المنتصف (يجمع بين التحدي والكلمات)
- **اللون المميز:** `brand-orange` (#D84315) — نفس لون الهجوم في حرب الأسماء، لأن المطارحة مبارزة

# 2. رؤية المنتج

## 2.1 الجملة الواحدة

> مطارحة تحول وقت الانتظار بين الدورات إلى لحظات تحدي ملحمية — مبارزة كلمات 1v1 سريعة تُبقي اللاعبين في المنصة وتُثري الاقتصاد.

## 2.2 المشكلة التي نحلها

| المشكلة | كيف مطارحة تحلها |
|---------|------------------|
| اللاعبون يفتحون المنصة مرة باليوم ويطلعون | مطارحة تعطيهم سبب يرجعون — "فيه ناس في اللوبي، أروح ألعب" |
| الاقتصاد ينحدر (نقاط تنزل بدون مصدر كافي) | مطارحة zero-sum — لا تضخم ولا انكماش، تنقل النقاط بين اللاعبين |
| ما فيه تفاعل مباشر بين اللاعبين | مطارحة 1v1 مباشرة — أول تفاعل حقيقي بين لاعبين في المنصة |
| المنافسة بس على الترتيب العام | لوحة ترتيب مطارحة مستقلة — نوع جديد من المنافسة |

## 2.3 مؤشرات النجاح (Success Metrics)

| المؤشر | الهدف | كيف نقيسه |
|--------|------|----------|
| **نسبة التجربة** | 60% من اللاعبين النشطين يجربون مطارحة خلال أسبوع | عدد اللاعبين الفريدين / إجمالي النشطين |
| **معدل العودة** | 40% يلعبون أكثر من مباراة واحدة | لاعبون بأكثر من 1 مباراة / إجمالي المجربين |
| **مدة الجلسة** | +5 دقائق متوسط الوقت في المنصة | مقارنة قبل/بعد إطلاق مطارحة |
| **صحة الاقتصاد** | صافي النقاط المنقولة = 0 (zero-sum) | مجموع MINIGAME_PAYOUT - مجموع MINIGAME_BUY_IN |
| **معدل الإكمال** | أقل من 15% انسحاب | جلسات ABANDONED / إجمالي الجلسات |
| **NPS (رضا)** | "هل توصي صديقك يلعب مطارحة؟" > 7/10 | استبيان داخلي |

# 3. الجمهور المستهدف (Target Users)

## 3.1 شخصيات المستخدمين (User Personas)

### فيصل — "المنافس الشرس"
- **العمر:** 22
- **السلوك:** يفتح المنصة 5 مرات باليوم، يتابع الترتيب، يهاجم كل ما يقدر
- **ما يحبه في مطارحة:** سلسلة الانتصارات + لوحة الترتيب المستقلة + التحدي المباشر
- **خطر:** يحاول يستغل النظام (يتفق مع صديقه يخسر له)
- **كيف نتعامل:** حد خصم واحد لكل دورة + تسجيل مخاطر

### نورة — "اللاعبة الكاجوال"
- **العمر:** 19
- **السلوك:** تفتح المنصة مرة باليوم، تجاوب الأسئلة، ما تهاجم كثير
- **ما يحبها في مطارحة:** الأنيميشن السينمائية + الكلمات النجدية + إنها سريعة
- **خطر:** تخاف تخسر 500 نقطة
- **كيف نتعامل:** شاشة الخسارة فيها تشجيع + المبلغ واضح قبل الدخول

### عبدالله — "المشرف المراقب"
- **العمر:** 28
- **السلوك:** يدير المسابقة، يتابع الإحصائيات، يعدل الإعدادات
- **ما يهمه في مطارحة:** مفتاح الإيقاف + رؤية المباريات + تأثير على الاقتصاد
- **خطر:** يعطل اللعبة بدون سبب
- **كيف نتعامل:** 3 مستويات إيقاف (ناعم/صلب/طوارئ) + إحصائيات واضحة

# 4. رحلات المستخدم (User Journeys)

## 4.1 الرحلة الأولى — اكتشاف مطارحة

```
[لوحة اللاعب] 
    → يشوف أيقونة "مطارحة" مع نبضة خضراء "٣ لاعبين في اللوبي"
    → يضغط عليها
    → [لوبي مطارحة]
        → يشوف اللاعبين المتصلين + أسماءهم المستعارة
        → يشوف شريط نتائج حديثة (الصقر فاز على الفهد — 3 دقائق)
        → يشوف إحصائياته (أول مرة: 0-0-0)
    → يختار: "تحدي لاعب" أو "مستعد للمبارزة" (طابور)
```

### لحظة الحقيقة الأولى: "هل أنا فاهم اللعبة؟"

قبل أول مبارزة، اللاعب يحتاج يفهم:
1. بدفع 500 نقطة دخول
2. بختار 5 كلمات سرية
3. بحاول أخمن كلمات الخصم
4. فيه أدوات تساعدني (لكن لها تكلفة)
5. الفائز ياخذ 1000 نقطة

**كيف نوصّل هذا؟** شاشة "كيف تلعب" مبسطة (3 خطوات + أيقونات) تظهر مرة واحدة فقط عند أول دخول للوبي. بعدها ما تظهر أبداً.

## 4.2 رحلة التحدي المباشر

```
[اللوبي]
    → اللاعب يشوف "الصقر" حالته: idle
    → يضغط "⚔️ تحدي" بجانب اسمه
    → ينتقل لـ [ساحة الدخول] — لقبه يدخل من اليمين
    → الجهة المقابلة: لقب الصقر + "بانتظار الرد..."
    
    الصقر يشوف في اللوبي:
        → popup: "تحداك الفهد في مطارحة! ⚔️"
        → زرين: [قبول] [رفض]
    
    إذا قَبِل:
        → كلا اللاعبين ينتقلون لـ [ساحة الدخول]
        → لقب الخصم يظهر بتأثير "slam"
        → عداد: ٣... ٢... ١... ابدأ!
        → [اختيار الكلمات] → [المبارزة] → [النتيجة]
    
    إذا رفض:
        → الرافض يشوف "تم الرفض"
        → المتحدي يشوف "الصقر رفض التحدي" (بدون عقوبة)
        → يرجع للوبي
```

## 4.3 رحلة الطابور التلقائي

```
[اللوبي]
    → يضغط "مستعد للمبارزة 🎯"
    → حالته تتغير في اللوبي لـ "في الطابور"
    → [ساحة الدخول] — لقبه يدخل + ظل نابض في الجهة المقابلة
    → يسمع موسيقى انتظار خفيفة
    
    لاعب ثاني يدخل الطابور:
        → التوفيق الفوري (FIFO)
        → الظل يتحول للقب الخصم بتأثير "slam"
        → ٣... ٢... ١... ابدأ!
    
    إذا ما لقى أحد خلال دقيقتين:
        → "ما فيه خصوم متاحين حالياً 😴"
        → يرجع للوبي (بدون عقوبة)
```

## 4.4 رحلة المبارزة الكاملة

```
[اختيار الكلمات — 45 ثانية]
    → 10 بطاقات كلمات (مختلطة الفئات)
    → كل بطاقة: الكلمة + أيقونة الفئة + لون
    → اللاعب يضغط على 5 بطاقات
    → بطاقة مضغوطة = تتوهج بلون ذهبي
    → زر "إعادة سحب 🔄" (تكلفة -20 من الأرباح)
    → زر "جاهز ✓" يظهر بعد اختيار 5
    → إذا انتهى الوقت بدون 5: النظام يختار عشوائي

[المبارزة — 12 دور × 30 ثانية]
    → الشاشة: كلمات الخصم (مخفية ■■■■■) في الأعلى
    → أدوات الاستنتاج في المنتصف
    → كلماتي (مرئية ★★★★★) في الأسفل
    → مؤقت + رقم الدور في الأعلى

    دوري:
        → أختار أداة أو أخمن مباشرة
        → النتيجة تظهر فوراً مع أنيميشن
        → الدور ينتقل للخصم

    دور الخصم:
        → "دور الخصم..." مع أنيميشن انتظار
        → لما ينتهي: أشوف نتيجة إجراءه
          — "الخصم استخدم أداة 🔍" (بدون تفاصيل)
          — أو "الخصم خمّن كلمتي ✅" (كلمتي تتحول للأحمر)
          — أو "الخصم أخطأ ❌"

[الوقت الإضافي — إذا تعادل]
    → الشاشة تنبض بالأحمر
    → "⚡ الوقت الإضافي ⚡"
    → 3 أدوار + 20 ثانية + تكاليف مضاعفة
    → ضغط نفسي عالي — لحظة ملحمية

[شاشة النتيجة — HERO]
    فوز:
        → شاشة ذهبية كاملة
        → لقبي بحجم كبير
        → "+340 نقطة" تعدّ بأنيميشن
        → "🔥 سلسلة 5 انتصارات!"
        → تفاصيل: تخمينات صحيحة، أدوات، مدة
        → [عودة للوبي] أو [تحدي مرة ثانية]

    خسارة:
        → شاشة داكنة بدون احتفال
        → "-500 نقطة" + لقب الخصم الفائز
        → تفاصيل المباراة
        → "المحاولة الجاية أفضل 💪"
        → [عودة للوبي]
```

# 5. الأدوات من منظور المستخدم

## 5.1 ليش الأدوات مهمة؟

الأدوات هي اللي تحول المطارحة من "تخمين عشوائي" لـ "استنتاج ذكي". بدون أدوات، اللاعب يخمن من الهواء. مع الأدوات، يبني نظرية ويضيّق الاحتمالات.

## 5.2 كيف يشوفها اللاعب

| الأداة | كيف تظهر في الواجهة | ماذا يحدث | التكلفة |
|--------|---------------------|----------|--------|
| **كشف حرف** | أيقونة 🔤 + "هل فيه حرف...؟" → لوحة أحرف يختار منها | النظام يجاوب: "نعم (في 3 كلمات)" أو "لا" | -20 |
| **طول الكلمة** | أيقونة 📏 + "كم طول كلمة؟" | النظام يكشف: "الكلمة الثالثة: 4 أحرف" | -20 |
| **حذف حروف** | أيقونة ✂️ + "شيل حروف ما تفيد" | 3 حروف تختفي من الأبجدية بلون أحمر | -40 |
| **أول حرف** | أيقونة 🎯 + "وش أول حرف؟" → يختار أي كلمة (1-5) | الحرف الأول يظهر على البطاقة بأنيميشن flip | -50 |
| **تضييق** | أيقونة 🔍 + "ضيّق الاختيارات" | 3 بطاقات تظهر: وحدة صح واثنتين خدع | -60 |
| **تخمين مباشر** | أيقونة ⚡ + حقل كتابة أو اختيار | صح = كلمة تنكشف ✅ / خطأ = البطاقة تهتز ❌ | 0 صح / -50 خطأ |

## 5.3 استراتيجية اللعب المثالية

```
المبتدئ (أول 3 مباريات):
    → يستخدم "كشف حرف" كثير (رخيصة)
    → يتعلم الأحرف الشائعة
    → يخمن مبكر (كثير أخطاء)
    → ينفذ ميزانيته بسرعة

المتوسط (بعد 5-10 مباريات):
    → يبدأ بكشف الحروف الأكثر تمييزاً (ض، ذ، خ)
    → يستخدم "طول الكلمة" لتصفية الاحتمالات
    → يخمن بعد 3-4 أدوات

المحترف:
    → يبدأ بالحروف اللي تميز بين الفئات (مدن vs حيوانات)
    → يستخدم "حذف حروف" مبكر (يضيّق 28 حرف لـ 25)
    → يستخدم "تضييق" بذكاء (يختار الكلمات الصعبة)
    → يخمن بعد 2 أدوات فقط — أعلى ربح صافي
```

# 6. واجهة المستخدم — مواصفات تفصيلية

## 6.1 بطاقة مطارحة في صفحة الألعاب المصغرة

```
┌──────────────────────────────────┐
│  ⚔️  مطارحة                     │
│  مبارزة كلمات 1v1               │
│                                  │
│  🟢 ٣ لاعبين في اللوبي الآن     │
│                                  │
│  إحصائياتي: 5-2 (71% فوز)       │
│  🔥 سلسلة: 3 انتصارات           │
│                                  │
│  ┌────────────────────────────┐  │
│  │     ادخل اللوبي ⚔️        │  │
│  └────────────────────────────┘  │
└──────────────────────────────────┘
```

- النبضة الخضراء 🟢 تظهر فقط عندما يكون في اللوبي لاعب واحد على الأقل
- إذا ما لعب قبل: "جرّب مطارحة!" بدل الإحصائيات
- الدخول للوبي يتطلب رصيد ≥ مبلغ الدخول (500)

## 6.2 شاشة اللوبي

```
┌──────────────────────────────────┐
│  ← مطارحة                       │
│  رسوم الدخول: 500 نقطة          │
├──────────────────────────────────┤
│                                  │
│  لاعبون متصلون (4)              │
│  ┌────────────────────────────┐  │
│  │ الصقر    🟢 idle   [⚔️]   │  │
│  │ الفهد    🟡 in_queue       │  │
│  │ الشهم    🟢 idle   [⚔️]   │  │
│  │ الليث    🔴 in_match       │  │
│  └────────────────────────────┘  │
│                                  │
│  نتائج حديثة                    │
│  ┌────────────────────────────┐  │
│  │ الصقر فاز على النمر (5 د)  │  │
│  │ الشهم فاز على الفهد (8 د)  │  │
│  └────────────────────────────┘  │
│                                  │
│  ┌────────────────────────────┐  │
│  │   مستعد للمبارزة 🎯       │  │
│  └────────────────────────────┘  │
│                                  │
│  إحصائياتي  |  لوحة الترتيب     │
└──────────────────────────────────┘
```

- `[⚔️]` زر التحدي المباشر — يظهر فقط بجانب لاعبين حالتهم `idle`
- لاعب في `in_queue` — لا يمكن تحديه (بانتظار التوفيق)
- لاعب في `in_match` — لا يمكن تحديه (يلعب حالياً)
- زر "مستعد للمبارزة" يدخلني الطابور مباشرة

## 6.3 ساحة الدخول (Battle Arena)

شاشة سينمائية كاملة — **لا هيدر، لا فوتر، لا نافبار**. مثل شاشة اللوبي (09) في النماذج الأولية — غامرة بالكامل.

```
┌──────────────────────────────────────────┐
│                                          │
│         خلفية داكنة #111827              │
│    عناصر سداسية متحركة في الخلفية       │
│                                          │
│                                          │
│   [لقبي]  ←───  VS  ───→  [خصمي]       │
│   الفهد          ⚔️         ???          │
│                                          │
│                                          │
│        ٣ ... ٢ ... ١ ... ابدأ!          │
│                                          │
│                                          │
└──────────────────────────────────────────┘
```

- لقبي يدخل من اليمين (RTL)
- الخصم: ظل نابض (طابور) أو لقب + "بانتظار الرد..." (تحدي)
- عند التوفيق: لقب الخصم يظهر بتأثير "slam" من اليسار
- العد التنازلي: أرقام كبيرة في المنتصف مع pulse effect

- الألوان حسب الفئة: حيوانات=أخضر، مدن=أزرق، أكلات=برتقالي، أسماء=بنفسجي، تراث=ذهبي

# 7. حالات خاصة من منظور المستخدم

## 7.1 الخصم ينقطع

```
→ الشاشة تُظهر: "الخصم انقطع... ⏳ 0:45"
→ عد تنازلي (60 ثانية افتراضي)
→ اللاعب ينتظر (لا يقدر يسوي شيء)
→ إذا الخصم رجع: اللعبة تستمر من حيث وقفت
→ إذا ما رجع: "الخصم انسحب — فزت! 🎉"
→ يكسب كامل المبلغ (1000 نقطة)
```

## 7.2 أنا أنقطع (إنترنت ضعيف)

```
→ الشاشة تُظهر: "إعادة الاتصال..." مع spinner
→ إذا رجع الإنترنت: اللعبة تستمر تلقائياً
→ إذا ما رجع خلال 60 ثانية: خسرت (500 نقطة)
→ ملاحظة: اللعبة تحاول إعادة الاتصال تلقائياً — اللاعب ما يحتاج يسوي شيء
```

## 7.3 رصيدي ما يكفي

```
→ في اللوبي: زر "مستعد للمبارزة" معطل
→ رسالة: "رصيدك الحالي 200 نقطة — تحتاج 500 للدخول"
→ الحل: اكسب نقاط من الأسئلة أو الهجمات
```

## 7.4 وصلت الحد اليومي

```
→ في اللوبي: كل أزرار التحدي والطابور معطلة
→ رسالة: "لعبت مباراتين اليوم — ارجع بكرة! 📅"
→ عداد: "المباراة الجاية تتوفر بعد: 5 ساعات 23 دقيقة"
```

## 7.5 الوقت الإضافي — التعادل

```
→ انتهت 12 دور + تعادل في عدد التخمينات + تعادل في التكلفة
→ الشاشة تتحول للأحمر مع نبض
→ "⚡ الوقت الإضافي ⚡"
→ 3 أدوار إضافية، 20 ثانية، تكاليف ×2
→ إذا ما زال تعادل بعد الوقت الإضافي:
  → الفائز = اللي أنفق أقل (الأذكى)
  → إذا تعادلوا بالضبط: اللاعب الثاني يفوز (تعويض عن ميزة البداية)
```

# 8. المتطلبات غير الوظيفية (Non-Functional Requirements)

## 8.1 الأداء

| المتطلب | الهدف |
|---------|------|
| وقت تحميل اللوبي | أقل من 1.5 ثانية |
| استجابة الأداة (من الضغط للنتيجة) | أقل من 300ms |
| استجابة التخمين | أقل من 500ms |
| حجم رسالة WebSocket | أقل من 2KB لكل رسالة |
| أقصى مدة مباراة | 15 دقيقة (مع وقت إضافي) |

## 8.2 التوافق

| البُعد | المتطلب |
|--------|---------|
| الموبايل | يعمل على 360×780 (Galaxy S25) — الهدف الأول |
| المتصفحات | Chrome, Safari (iOS), Samsung Internet |
| الاتجاه | RTL بالكامل |
| الوضع المظلم | يعمل في كلا الوضعين |
| الإنترنت | يتحمل انقطاع لحظي (إعادة اتصال تلقائية) |

## 8.3 الأمان

| المتطلب | التنفيذ |
|---------|--------|
| لا يقدر اللاعب يشوف كلمات الخصم | `build_public_view` يحذف كلمات الخصم من الحالة |
| لا يقدر يرسل إجراء في غير دوره | `validate_action_envelope` يتحقق من الدور |
| لا يقدر يرسل إجراء مكرر | `check_idempotency` يتحقق من `action_id` |
| لا يقدر يعدل على رصيده | كل النقاط تمر عبر الدفتر (Ledger) |

# 11. ملحق — مقارنة BRD vs PRD

| البُعد | BRD (موجود) | PRD (هذا المستند) |
|--------|-------------|-------------------|
| الجمهور | المطوّر | فريق المنتج + التصميم + التطوير |
| اللغة | تقني — نماذج بيانات، APIs | منتج — رحلات مستخدم، واجهات |
| المحتوى | plugin contract, settings schema, ledger types | قصص مستخدم، wireframes, نصوص عربية |
| الهدف | "كيف نبنيها" | "ليش نبنيها وكيف يحس بها اللاعب" |
| المرجع | Minigame Engine BRD + Mutaraha BRD | هذا المستند يُكمّل الـ BRD، لا يحل محله |
